# MedClass - Sistema de Triagem de Pacientes

Projeto desenvolvido em Python com foco em classificação inicial de risco de pacientes.

## Funcionalidades
- Cadastro simples de paciente
- Coleta de sintomas
- Classificação básica de risco
- Exibição do resultado final

## Tecnologias
- Python 3

## Como executar
```bash
python app.py
